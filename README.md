# 知知 · Knowledge Garden

一个无需域名和服务器的个人知识库。网站可免费部署到 **GitHub Pages**，而你的书籍、知识卡片和洞见默认只保存在你自己的浏览器中（`localStorage`）。

## 已实现的可用功能

- **书架管理**：创建、编辑、删除书籍；记录作者、领域、阅读状态和评分。
- **知识卡片**：创建、编辑、删除知识点；保存原文、个人理解、应用场景、标签与重要性。
- **TXT / Markdown 导入**：新建书籍时可上传 `.txt` / `.md` 或粘贴文本；系统会按段落和句子生成待整理卡片。
- **知识关联与地图**：在卡片编辑器勾选关联卡片，知识地图会用真实数据绘制节点和连接。
- **全局搜索**：检索书名、作者、分类、标签、原文、理解和应用场景。
- **本地知识助手**：按问题关键词在你的卡片中排序检索；数据不会发送到第三方。
- **备份和恢复**：下载完整 JSON 备份，并可在同一浏览器或另一台设备导入恢复。
- **自动保存**：每次修改会自动保存到当前浏览器。

## 使用方式

1. 打开网站，点击 **新书** 创建一本书。
2. 粘贴读书笔记，或导入 TXT / Markdown 文本，生成待整理卡片。
3. 打开卡片补充自己的理解和应用场景；勾选相关卡片建立连接。
4. 定期点击左下角 **下载知识库备份**，妥善保存 JSON 文件。
5. 在新电脑或浏览器中使用时，点击 **导入知识库备份** 恢复数据。

> 浏览器的本地数据会在清除网站数据、使用无痕模式或更换浏览器时丢失，因此 JSON 备份很重要。

## 本地开发

```bash
npm install
npm run dev
npm run lint
npm run build
```

## GitHub Pages 部署结构

- `main`：GitHub Pages 使用的纯静态构建文件。
- `source`：完整的 React / Vite 源码。

## 当前限制

GitHub Pages 是静态托管，不能安全保存 OpenAI、Claude 等 API 密钥。本版本提供的是离线文本拆卡和本地检索；真实的 PDF 解析、云端同步、登录和 AI 问答，需要额外接入后端或由用户自行提供 API 服务。
