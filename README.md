# 知知 · Knowledge Garden

一个本地优先的个人阅读与知识工作台。保留深绿、暖纸色与木质书架，将记录、阅读、提炼、找回和复用整合成一条流程。

## 核心入口

- **工作台**：继续阅读、快速记录、待整理内容、最近修改、轻量复习入口。示例档案由用户手动选择，不自动混入个人资料。
- **资料库**：书架 / 列表视图、分类与阅读状态筛选、排序。阅读档案集中呈现完整正文、章节、本书卡片、结构与双向关联。
- **知识卡片**：独立收集箱、标签与来源筛选、分页、批量标签、移动归属、归档与回收站。无书籍时也可直接记录。
- **全局搜索**：书名、作者、分类、章节全文、卡片原文、个人理解、标签和应用记录；点击结果回到来源。不连接外部 AI 服务。
- **更多与数据管理**：导入、JSON 导出与恢复、最近 20 个内容修改前的版本快照、回收站、可选 GitHub 加密同步。
- **轻量复习**：查看线索、记录掌握程度、安排下次复习；卡片可追加真实应用记录。

手机和窄屏平板提供固定底部主导航。页面和阅读章节使用 URL hash 路由，支持刷新和浏览器前进 / 后退。

## 数据保护

### 本地保存与迁移

正式数据保存在当前网站来源的 **IndexedDB** 中。首次使用升级版时，读取原有 `knowledge-garden-v3` / `knowledge-garden-v2` 数据并迁移；原始 localStorage 内容不删除。格式异常时显示恢复提示并允许下载原始数据，不将错误静默解释成空库。

多个标签页通过事务读取最新版本再修改，并广播已保存的版本。写入失败时保留当前输入和稳定的实体 ID；可重试或先导出，不假装保存成功。书籍、卡片、章节草稿按标签页隔离，刷新或关闭编辑器后可恢复。

删除书籍 / 卡片先进入回收站。重新导入保留人工理解、应用、有效关联、手工章节与未匹配的旧卡片；原文不冒充个人洞见。已手工编辑的原章节不会被新源文件静默替换。

### 备份与恢复

从“更多与数据管理”导出完整 JSON。恢复前显示数量和方式，默认合并保留双方；明确选择替换时再次确认，并保留恢复前快照。恢复后暂停同步，避免旧云端内容立即覆盖本机恢复结果。

**JSON 备份包含明文笔记**，请妥善保管。快照也保存在同一浏览器中，不能代替异地备份。清除网站数据、无痕会话结束、更换浏览器或网站来源，都可能失去本地数据；升级前后都应保留独立备份。

### 可选 GitHub 加密同步

只连接用户指定的私有仓库，在浏览器内以 PBKDF2 + AES-GCM 加密知识库，再使用 Contents API 同步。首次连接或冲突时先预览并确认；已有共同版本时采用三方合并，冲突内容保留副本，云端写入使用 SHA 版本校验。请求失败 / 版本冲突会暂停，不盲目重试覆盖。

保存的连接在重新打开时恢复为 **暂停**，不会启动就请求云端、替换或上传本机数据。用户手动检查并确认后才恢复同步。

默认不记住访问令牌和加密密码。勾选“在此设备记住”会把这些凭据存入当前浏览器，应只在可信个人设备上使用；“断开并清除凭据”可移除它们。加密密码丢失时无法解密云端文件，明文 JSON 备份可独立恢复。

## 本地开发与验证

本次验证环境：Node.js 24。

```bash
npm install
npm run dev
npm run lint
npm run build
npm test
```

模型与同步协议测试使用 Node 内置测试运行器，GitHub 请求全部模拟，不需要真实令牌，不访问用户数据。测试加载器直接使用项目已安装的 TypeScript，不向源码目录输出编译文件。

### 浏览器回归

浏览器测试需要 Playwright 运行库和 Chromium / Chrome / Edge。运行库可安装在本项目，也可由环境提供：`PLAYWRIGHT_MODULE_PATH` 指向包目录，`BROWSER_EXECUTABLE` 可指定浏览器可执行文件。

先启动本地 Vite（示例端口 5179），再执行：

```bash
npm run dev -- --host 127.0.0.1 --port 5179 --strictPort
# 另一个终端
npm run test:browser
```

`TEST_BASE_URL` 默认为 `http://127.0.0.1:5179`，只允许本机地址。测试使用新的临时浏览器上下文，不连接日常浏览器配置；除模拟的 GitHub API 外，所有外部请求均被阻止。

覆盖真实 IndexedDB 事务、多标签页保存、写满重试、快照上限、草稿、编辑层级、正文摘录、阅读恢复、导入与备份恢复、批量整理、复习、启动同步保护，以及 320 / 375 / 390 / 414 / 768 / 1440 像素布局。

截图与结果默认输出至 `.tools/upgrade-verification`（已忽略），可通过 `QA_ARTIFACT_DIR` 改到专用验收目录。

## 范围与限制

- 本次升级仅在本地完成，**不包含发布 / 部署**。
- 未接入真实 AI 问答、PDF 解析、社交分享或复杂全局知识图谱；结构视图展示真实章节与手动关联。
- GitHub 同步不是实时多人协作服务。断网时可继续本地工作，恢复网络后仍需处理同步状态。
- 自动测试使用桌面浏览器及手机尺寸模拟；不等于真实手机、真实仓库和线上环境已经完成实测。
